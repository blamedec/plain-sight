# Plain Sight

A daily hide and seek painting game, built as a playable demo.

Paint yourself into a busy pixel-art picture, then hunt for everyone else. Rarer finds score more, and each night an X-ray shows where everyone was hiding.

Everyone else in the demo is simulated. Use the controls above the panel to skip to the next day, reset, or see how the reveal could look on stream.

Play it here: https://blamedec.github.io/plain-sight/
